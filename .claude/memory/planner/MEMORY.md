## Gatekeeping discipline

Can record:
- design patterns (those that recur across tasks)
- author preferences (learned from how handoffs get revised)
- working habits ("look up X before designing")

Cannot record:
- judgments on a solution's quality
- evaluations of other roles
- single-task specifics
