## Why now

Week 0 计划 5-7 天，实际**1 天**全部塞完 + 顺路推进了 Week 1（H018-H021,
H022 进行中）。22 个 handoff，5 个 ADR，多个 bitter lesson。趁热打铁写
retro，**沉淀方法论 + 找系统性改进 + 把 bitter lesson 固化进 docs/**。

retro 不只是"写感想"，是 multi-agent collaboration 实战出来的**经验包**，
给后面 Week 1 → Week 4 用。也是答辩里"agent-arch 创新性"那部分的关键素材
（不只项目本身做了什么，还要讲怎么做的）。

跟 H023 同模式：planner self → planner self，**写 doc 不动代码**。
sandbox-friendly。

## Objective

写 `docs/retros/week0.md`（~300-400 行），分 6 段：

1. **目标 vs 实际**：roadmap §Week 0 vs done
2. **handoff 流水**：22 个 handoff 时间线 + 类型分布 (codex spike + planner
   unblock + user-led + agent autonomous)
3. **ADR 决策史**：5 个 ADR (0001-0005) 触发场景 + 影响
4. **Bitter lessons 集中收纳**：本 retro 是 lesson 的**集合点**，每条带
   "触发场景 + 教训 + 已回灌位置 (或 待回灌)" 三列
5. **agent-arch 实战回顾**：planner/executor/auditor 三角色实际怎么协作的，
   特别是 codex-as-executor + planner-as-unblocker 模式怎么演化出来的
6. **Week 1 启动建议**：基于 retro 总结，Week 1 应该做什么调整
